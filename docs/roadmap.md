# Roadmap

## 0.1 — Fondasi

- [x] Rancangan visual dan arsitektur.
- [x] Desktop, Console, Dock.
- [x] Discovery Steam/Epic dan file manual.
- [x] Favorit, recent, search, artwork lokal.
- [x] Input keyboard dan XInput dasar.
- [x] Build portable Windows melalui GitHub Actions.
- [ ] Validasi visual dan controller pada laptop pengguna.

## 0.2 — Pengalaman konsol

- [ ] Fullscreen borderless pada monitor pilihan, termasuk multi-monitor.
- [ ] Animasi mode dan perpindahan cover yang menjaga frame time.
- [ ] Fokus kembali ke launcher setelah game selesai.
- [ ] Gamepad-only settings dan on-screen keyboard.
- [ ] Import shortcut Start Menu/Desktop dengan konfirmasi hasil.
- [ ] Artwork cache Steam baru, provider metadata opsional.
- [ ] Posisi/ukuran tersimpan, tray, rename dan per-game settings.

## 0.3 — Distribusi

- [ ] Installer dan uninstall startup yang bersih.
- [ ] Penandatanganan digital dan update terverifikasi.
- [ ] Dukungan controller tambahan / Windows.Gaming.Input.
- [ ] Uji aksesibilitas, monitor/DPI dan konsumsi daya laptop.

Tidak ada penggantian shell Explorer otomatis dalam roadmap awal.
